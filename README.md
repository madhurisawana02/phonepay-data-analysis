# PhonePe Pulse Data Analysis

## Project Overview
This project analyzes PhonePe Pulse data to understand transaction trends, user registrations, and geographical patterns across India.

## Tools Used
- Python
- Pandas
- Google Colab
- SQL
- Power BI

## Data Processing
- Extracted data from JSON files
- Cleaned and transformed data using Pandas
- Created structured DataFrames
- Analyzed state, district, year, and quarter-level data

## Analysis
The project focuses on:
- Transaction trends
- Registered users
- State-wise analysis
- District-wise analysis
- Year and quarter-wise trends

## Dashboard
Created a Power BI dashboard to visualize the analysis and identify key insight
